# Rahul Tanwar – Portfolio

## Video links kaise daalein
`index.html` kholo, `<script>` ke top pe "EDIT HERE" section hai:
- `FEATURED = ""` mein jis project ka title likhoge, woh hero mein bada dikhega
- `PROJECTS` mein har project ke `video: ""` mein link
- Chalega: YouTube (video/Shorts), Instagram reel, Vimeo, Google Drive ("Anyone with the link"), ya .mp4
- `thumb: ""` optional hai. YouTube ka thumbnail apne aap aa jata hai.

## Vercel pe live karna
1. github.com pe New repository banao (Public), naam: rahul-portfolio
2. "uploading an existing file" pe click karke `index.html`, `resume.pdf`, `README.md` drag kar do, Commit
3. vercel.com pe GitHub se login karo, Add New, Project, apna repo Import, Deploy
4. Link milega: rahul-portfolio.vercel.app

Baad mein koi change: GitHub pe file replace karo, Vercel apne aap update kar dega.
